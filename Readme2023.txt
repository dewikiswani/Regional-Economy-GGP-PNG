2023 Social Accounting Matrix for Papua New Guinea
Country: Papua New Guinea
Year: 2023
Units: Millions of PNG Kina

Citation requirement: The users of 2023 Social Accounting Matrix for Papua New Guinea Dataset are required to cite both the dataset and the associated data paper. Please see below for the recommended citation.

Dataset: International Food Policy Research Institute (IFPRI). 2025. 2023 Social Accounting Matrix for Papua New Guinea. Washington, DC: IFPRI [dataset]. https://doi.org/10.7910/DVN/VXRM8G. Harvard Dataverse. Version 1.

Data Paper: International Food Policy Research Institute (IFPRI). 2025. 2023 Social Accounting Matrix for Papua New Guinea (PNG): A Nexus Project SAM. Data Paper. Washington, DC: IFPRI. handle 10568/178963 https://hdl.handle.net/10568/178963.

Data files in this dataset:
1. IFPRI_SAM_PNG_2023_POP - This file contains information on "Representative Household Populations" measured in 1000s of people..
2. IFPRI_SAM_PNG_2023_SAM - This file contains the main data table of social accounting matrix (SAM).
